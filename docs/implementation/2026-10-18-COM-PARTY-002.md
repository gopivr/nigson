## Summary

Implemented API-066 `GET /api/v1/me/organizations` as a Commerce-owned read. It derives the current customer from the trusted server-side session, returns only that actor’s active memberships in active organizations, and projects the exact configured Commerce entitlement state (`PENDING` when no entitlement exists). Suspended memberships disappear; suspended entitlements remain visible as `SUSPENDED`. The endpoint rejects query arguments and request bodies and uses the existing authenticated BFF chain. No Experience tables or shared cross-owner records are accessed.
