## Summary

Implemented API-067, `PUT /api/v1/staff/organizations/{id}/price-assignment`, over the existing Commerce-owned BP3 assignment and wholesale-rule tables. Current SALES authorization, CSRF, idempotency and If-Match protect the command. A single Commerce transaction validates the active effective DISTRIBUTOR book and enabled NG/NGN2 market, validates eligible SKU quantity scales and exact money minor units, versions the assignment, replaces the organization's market rule set, appends a redacted audit record and EVT-007, then stores the response for replay. A failed audit/event or stale version leaves no partial assignment.

Rule resolution now applies each field independently: organization-specific values override market defaults, SKU-specific values override generic values within each scope, SKU and configured pack multiples combine with an exact least common multiple, and order minimum remains a separate checkout subtotal check. The command never changes organization or entitlement state, including when those states are suspended. No DDL, owner boundary, provider call, business price or activation input was added.
