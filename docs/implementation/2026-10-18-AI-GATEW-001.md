## Summary

Implemented AI-owned APIs 166, 167, 168 and 178. Model-policy creation validates bounded Bedrock policy parameters and creates a disabled revision. Activation requires an exact current `If-Match`, recent MFA, an explicitly configured model capability, a configured effective rate and a passing evaluation result bound to the same policy and prompt revisions. Prompt revisions are immutable and accept only allowlisted interpolation slots; free-text reasons are represented in audit by checksums. Rate revisions are immutable and require a deployment-allowlisted approval reference, stored in audit only as a checksum. Idempotency records serialize repeated commands, reject changed request bodies and return stable responses.

The owner-local budget helper uses the existing `ai.ai_run` and `ai.idempotency_record` tables. It reserves maximum configured input/output cost before a provider call, serializes model/currency reservations with PostgreSQL advisory locks, applies model-wide concurrency across rate revisions, and enforces daily UTC budget bounds. A known pre-acceptance provider outage may retry the same durable run after a fresh reservation check. An uncertain post-acceptance outcome retains its reservation and blocks a blind retry. Database transactions are short and are not held across provider HTTP. The deterministic stateful local mock bounds prompt/input/output/deadline values and supports replay, known outage, unknown acceptance and reconciliation. It is attached only in local/test; no real provider transport is wired by this increment.

There are no direct events or outbox effects for these APIs in the contract, and the existing AI tables already provide policy, prompt, rate, run, idempotency and append-only audit persistence, so no migration or outbox event was added. Gateway operation metrics use bounded owner/operation/outcome labels. Production model capabilities and rate approval references default empty; partial provider/model configuration fails startup. No model, rate, budget, retention value or policy approval is supplied by this change.
