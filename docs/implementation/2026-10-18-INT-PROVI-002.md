# INT-PROVI-002 implementation report

Specification: 1.1.0 / architecture 1.0 with ADR-008  
Task status: DONE (offline engineering; live Sheets account/recipient policy qualification remains NOT_RUN)  
Phase: EP07 / BP2 offline implementation

Implemented the EVT-024 Integration consumer and a durable SHEETS_SYNC path using Integration-owned `sheet_sync_record` and `integration_job`. The event consumer validates producer, envelope, application/opportunity IDs and the configured recipient group, then inserts a stable `career-sheet:<application>:<recipient-group>` job and owner-local audit in the inbox transaction. The worker obtains only the minimized API-128 Experience projection before opening Integration transactions. It fingerprints row contents with keyed HMAC, writes a stable row keyed by application ID, and stores only the fingerprint and provider row key in `sheet_sync_record`. Candidate values are formula-safe; approved answers are serialized into a stable single cell so varied application schemas cannot shift columns.

The Google Sheets adapter uses a signed service-account OAuth JWT and fixed Google OAuth/Sheets HTTPS hosts in live mode. A local/test stateful HTTP mock exercises the same token and REST code with synthetic credentials. Timeout after provider acceptance becomes UNKNOWN; reconciliation first searches the stable application ID. A real Sheets adapter never appends again when an uncertain write cannot be found; that job stays UNKNOWN for operator resolution. The mock uses an idempotent application-keyed upsert and can model accepted/before-acceptance timeouts. Provider calls and OAuth exchange are prohibited inside local transactions. No schema migration or cross-owner SQL was added.

Offline acceptance: six tests passed with zero failures/errors/skips across Integration's persistence/job tests, OAuth+Sheets HTTP local mock and module compatibility checks. The tests cover duplicate EVT-024 job delivery, recipient mismatch denial, row-key uniqueness, stale outcome fencing, formula injection, provider timeout after acceptance, and UNKNOWN reconciliation without duplicate rows.
