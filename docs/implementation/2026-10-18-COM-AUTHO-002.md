## Summary

Implemented API-117 as a private, exact-scope `nigson-experience` workload command. Commerce validates the NG/NGN2 market and configured entitlement key, creates or resolves the Commerce-owned organization, establishes the applicant as OWNER, optionally assigns an effective active distributor book, and commits `account_entitlement`, audit, and EVT-015 atomically before acknowledgment. Suspension commits the current entitlement state and EVT-015 before acknowledgment, so current organization purchasing authority denies immediately; it leaves organization membership records intact. Production entitlement activation fails closed until `NIGSON_PRICING_DISTRIBUTOR_ENTITLEMENT` is configured to the approved canonical key.

The command UUID is the durable idempotency identity, with the HTTP idempotency key and If-Match revision bound into its request hash. Matching retries return the stored response, changed input conflicts, wrong workload ownership/scope is denied, and stale revisions return 412. The API remains in Commerce’s owner boundary and does not query Experience tables or mutate staff roles.
