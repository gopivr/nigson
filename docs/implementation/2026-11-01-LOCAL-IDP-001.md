## Callback `AUTH_REQUIRED` follow-up (2026-11-01)

The supplied correlation ID has only the generic `AUTH_REQUIRED` request log and no sanitized OIDC exchange-denial entry. The callback handler intentionally returns the same safe error for a missing session cookie and an expired/mismatched one-time state, so the recorded logs cannot identify which condition caused this specific request. A failed or stale callback is one-use; users must begin a fresh sign-in from the MFE rather than reload the callback URL.
