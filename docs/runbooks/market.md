# Commerce market operations

API-169 requires current FINANCE, fresh MFA within15 minutes, encrypted BFF session CSRF and a stable Idempotency-Key. It creates only an explicitly named disabled market, version0/policyRevision1, empty tax policy/destinations and null returns/book. Supported active currency metadata must exist; NGN must retain minor_unit2. NGN-001 owns deterministic approved Nigeria currency/country seeds. An empty tax policy never means an approved zero rate.

API-162 requires FINANCE/MFA/CSRF, Idempotency-Key and quoted market If-Match. The selected book must be active RETAIL, matching currency and currently effective. Market version and policy revision increment atomically with EVT-008, redacted audit and the original replayable response. No provider request or automatic enablement occurs. New effective price revisions are separate pricing operations.

API-031 requires current CONTENT_PUBLISHER/CSRF/key and the Product aggregate If-Match. Missing product eligibility denies selling. The same commerce transaction stores the explicit eligibility/reason, touches product version/public revision, emits EVT-006 with current eligible enabled market codes, and appends redacted audit. The Product version avoids an undiscoverable separate first-eligibility revision; concurrent catalogue changes cause412. ADMIN/FINANCE do not imply publisher authority. Raw reasons are retained only in the owned restriction, not events/public DTOs/audit.

API-029 rejects all query parameters and bodies. It lists only enabled NG/NGN2 with enabled NG destinations, valid typed tax/address/returns policy and a currently effective RETAIL book. Invalid or incomplete draft policy is suppressed. International markets remain unavailable until BP5. Reads are repeatable-read/bounded and no-store; replica rate budget defaults1000/s and is configurable1..10000. This does not qualify production ingress capacity.

MarketEligibility is a local commerce checkout port and joins the caller transaction before stock mutations. It locks product UUIDs in PostgreSQL order, then market/currency, destination/book and eligibility, and validates current active product/restriction, approved NGN2, typed tax/returns/address/destination and effective book. AddressRules reuses the existing owned Party contract and pinned RE2/J engine/program ceiling10000, with postal inputs≤24. Current missing/expired/mismatched provider proof returns MARKET_RULE_VIOLATION422; production rejects MOCK/TEST. ProviderProof is a trusted local application value, has no HTTP deserializer or endpoint, and must be built by the owning payment/carrier qualification composition from actual currency/account/route/mode/revision evidence. An arbitrary approval reference is not genuine qualification evidence. The future COM-CART/COM-ORDER/PAYSTACK/CARRIER caller composition and real provider proofs remain separately NOT_RUN; offline tests use explicit synthetic proof and policy records only. StockLedger is not a market authorization shortcut.

All staff cached replies recheck current issuer/subject/Party role, and finance MFA, before replay; mutations stabilize current Party under SHARE. Lock waits500ms/statements2s, bounded idempotency waits; timeout/in-progress requires a bounded same-command retry, not a new key. All statements remain in commerce; no provider HTTP under transaction/lock. Currency/new market lock and finance book lock never hold Product; product restriction and checkout both lock Product before Market, avoiding reversed ordering.

Audits and outbox/response commit with mutations. Missing audit permission rolls everything back; restoring permissions and retrying the same command is safe. `nigson.market.commands` uses only operation CREATE/BOOK/ELIGIBILITY, increments after commit, and never labels business IDs/reasons. No task-owned retention purge is introduced. API-030/admin market policy activation remains the separate registered BP5 increment; API-169/162/031 cannot fabricate its approval. NGN-001 can seed approved disabled launch metadata independently, leaving actual tax/returns/prices/origin/service areas unresolved.
